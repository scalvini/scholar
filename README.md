# Scholar

> **Version:** 1.0
> **Last updated:** 7 October 2026

A weekly summary of new articles in communication, media studies and digital culture journals, published with GitHub Pages at https://scalvini.eu/scholar/. The page replaces scalvini.eu/scholar.html. It fetches the latest articles from the Crossref and OpenAlex APIs in the browser when you press Fetch, so it needs no updates.
